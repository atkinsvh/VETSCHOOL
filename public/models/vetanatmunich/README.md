# vetanatMunich Model Folder

Place manually obtained GLB files for the vetanatMunich registry here.

Examples:

```txt
public/models/vetanatmunich/osteophytes_cat.glb
public/models/vetanatmunich/skeleton_of_a_pig.glb
public/models/vetanatmunich/equine_reciprocal_apparatus_animation.glb
```

These paths match the entries committed to `assets/metadata/models.json`.
