# Model Folder

Place downloaded GLB/GLTF files here.

Configured target:

```txt
pig_skeleton.glb
```

The app expects it at:

```txt
/models/pig_skeleton.glb
```

In the actual project folder that means:

```txt
public/models/pig_skeleton.glb
```

vetanatMunich first-page registry targets live under:

```txt
public/models/vetanatmunich/
```
