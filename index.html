GLB Download Workflow

Use the downloader script to import direct .glb URLs and update manifest status:

  • scripts/download_glb_assets.py
  • python scripts/download_glb_assets.py --id dog_skeleton_001 --url https://...file.glb

Application

The interactive chapter portal starts at frontend/index.html and loads bundled local chapter, model, structure, and quiz data directly.
